# Official Provider & Client Brand Logo Assets

This directory contains sanitized, local, official brand vector assets (SVGs) for supported AI clients and providers in PromptRelay.

## Requirements Adherence
- **Zero Runtime Hotlinking:** All SVGs are stored locally in `dashboard/assets/providers/` and packaged with the application.
- **Sanitized Geometry:** All scripts, event handlers, external references, `xlink:href` remote image tags, and foreign objects have been stripped.
- **Fixed Dimensions & Ratios:** All assets specify fixed width/height and viewBox attributes to prevent layout shift.
- **Official Brand Sources:** Assets are extracted directly from official brand kits, simple-icons (CC0), and vendor production documentation.
